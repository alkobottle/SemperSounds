The font is embedded and referenced by family name rather than through an Avalonia
integration package. Projektanker.Icons.Avalonia was tried first and is built against
Avalonia 11, which throws MissingMethodException on TemplateBinding.ProvideValue at the
moment the first icon is measured under Avalonia 12 - a runtime failure with no build-time
warning. A font file has no such coupling to the toolkit's version.
